# SafeZone — Frontend

React + Vite admin dashboard for the SafeZone hazard reporting system.
See the top-level `README.md` (one folder up, in the SafeZone-System zip)
for full setup instructions covering both this frontend and the PHP/MySQL
backend.

Quick start:

```bash
npm install
npm run dev
```

Configure the backend URL in `src/api/config.js` (defaults to
`http://localhost/safezone-api`, matching a standard XAMPP install).
